Python Practice

Beginner Python exercises focused on building a foundation in Python programming.

**Exercises**

1) type_conversion.py — Practices user input, explicit type conversion, and Python data types (str, int, float, and bool).
   
3) bill_calculator.py — Practices user input, numeric type conversion, arithmetic operations, and rounding values to two decimal places.

**How to Run**

Make sure Python 3 is installed, then run an exercise from the terminal:

python type_conversion.py


or:

python bill_calculator.py


The programs will prompt you for input and display the results.

**Skills Practiced**

Python variables
User input with input()
Type conversion
Strings, integers, floats, and Booleans
Arithmetic operations
Rounding with round()
Basic output and f-strings
